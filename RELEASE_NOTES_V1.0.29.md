# Kasata v1.0.29

## Baru

- Kalkulator HPP per menu berbasis resep.
- Masukkan ukuran kemasan dan harga beli, lalu takaran per porsi untuk setiap bahan.
- HPP total otomatis mengisi produk dan dipakai sebagai harga modal laporan.
- Resep HPP ikut backup lokal dan sinkron ke cloud.
- Mendukung gram/kg, ml/liter, dan pcs dengan validasi satuan.

## Perbaikan

- Migrasi database lokal dan struktur cloud ditambahkan tanpa menghapus data menu lama.
- Penamaan aplikasi tetap kompatibel dengan updater Kasata.
