# Sajia v1.0.26

## Navigasi Android

- Tombol kembali dari halaman menu, laporan, settings, dan Lainnya kembali ke Kasir terlebih dahulu.
- Keluar aplikasi dari halaman Kasir membutuhkan dua kali tekan dalam dua detik untuk mencegah penutupan tidak sengaja.
- Dialog, bottom sheet, dan form tetap dapat ditutup dengan tombol kembali seperti biasa.
