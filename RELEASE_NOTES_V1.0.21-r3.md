# Sajia 1.0.21 (build 2024)

Perbaikan kenyamanan visual halaman login PIN.

- Latar login PIN kini memakai warna putih/off-white yang lebih nyaman dilihat.
- Panel, tombol angka, logo, dan teks memakai warna netral terang dengan kontras
  yang tegas.
- Warna hijau Sajia dipakai sebagai aksen pada PIN aktif, bukan sebagai warna
  penuh untuk seluruh halaman.
- Layout keypad ringkas untuk tablet 32-bit dari pembaruan sebelumnya tetap
  dipertahankan.

## Instalasi Android

- Versi tampilan tetap `1.0.21`; build Android diperbarui ke `2024` agar dapat
  dipasang sebagai pembaruan.
- Android 8.0 atau lebih baru.
- Pilih APK **V8A 64-bit** untuk kebanyakan perangkat baru.
- Pilih APK **V7A 32-bit** untuk tablet atau ponsel lama yang 32-bit.
