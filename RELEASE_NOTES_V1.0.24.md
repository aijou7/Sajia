# Sajia 1.0.24

## Pembaruan dari dalam aplikasi

- Sajia sekarang mengecek versi terbaru secara berkala saat aplikasi dibuka.
- Jika ada versi baru, aplikasi menampilkan dialog update dengan progres download.
- APK dipilih otomatis sesuai arsitektur perangkat (V7A 32-bit atau V8A 64-bit).
- File APK diverifikasi dengan checksum sebelum installer Android dibuka.
- Instalasi tetap dikonfirmasi oleh Android; Sajia tidak memasang aplikasi secara diam-diam.

## Instalasi Android

- Android 8.0 atau lebih baru.
- Pilih APK **V8A 64-bit** untuk kebanyakan perangkat baru.
- Pilih APK **V7A 32-bit** untuk tablet atau ponsel lama yang 32-bit.
