# Kasata v1.0.28

## Rebrand Kasata

- Nama aplikasi, splash, onboarding, pengaturan, dashboard owner, dan checkout
  sekarang tampil sebagai **Kasata**.
- Jalur update lama tetap dipertahankan agar pemasangan Sajia sebelumnya dapat
  menerima pembaruan langsung dari dalam aplikasi.
- Package ID Android, data lokal, route `/sajia`, dan URL manifest update tidak
  berubah sehingga akun, data outlet, dan lisensi tetap kompatibel.

## Cara memperbarui

- Buka **Pengaturan → Pembaruan aplikasi**.
- Tekan cek versi terbaru, download APK yang sesuai arsitektur perangkat, lalu
  ikuti konfirmasi instalasi Android.
