# Kasata v1.0.30

## Form menu lebih ringkas

- Harga jual tetap mudah diubah dari aplikasi kasir.
- Untuk outlet cloud, menu baru cukup mengisi satu HPP awal; resep dan buffer biaya selanjutnya dikelola dari Dashboard Owner.
- Menu cloud yang sudah ada hanya menampilkan HPP saat ini di form kasir.
- Untuk outlet offline/free, HPP manual dan kalkulator resep tetap tersedia di bagian **Biaya menu (opsional)**.
- Mengedit nama, harga, atau data menu lain dari aplikasi tidak lagi menulis ulang resep maupun mengganti HPP yang diatur Dashboard Owner.
- Resep lama yang masih menunggu sinkron tidak lagi menimpa resep yang sudah dikelola Dashboard Owner.

APK 32-bit dan 64-bit diperbarui bersamaan. Data menu yang sudah ada tetap dipertahankan.
