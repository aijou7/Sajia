# Sajia v1.0.27

## Pembaruan aplikasi dari Pengaturan

- Tambahkan tombol **Pembaruan aplikasi** di Pengaturan.
- Pemilik perangkat dapat mengecek versi terbaru kapan saja tanpa menunggu
  pemeriksaan otomatis saat aplikasi dibuka.
- Download dan instalasi tetap memakai APK yang sudah diverifikasi checksum.
