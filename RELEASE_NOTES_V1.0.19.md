# Sajia 1.0.19

Perbaikan kompatibilitas dan sinkronisasi outlet.

- APK terbaru kini universal: mendukung perangkat Android 8.0+ dengan ARM 32-bit
  dan ARM64, termasuk banyak tablet Android lawas.
- Outlet setup lama `Nama Kafe Saya` tidak lagi bisa tersinkron ke Cloud atau
  muncul sebagai cabang duplikat di dashboard owner.
- Data pemulihan akun hanya akan menarik outlet aktif yang sah dari Cloud.

## Instalasi Android

- Android 8.0 atau lebih baru.
- APK universal untuk `armeabi-v7a` dan `arm64-v8a`.
- Pengguna versi sebelumnya dapat memperbarui langsung tanpa uninstall.
- Build ini adalah distribusi langsung GitHub, bukan build Google Play.
