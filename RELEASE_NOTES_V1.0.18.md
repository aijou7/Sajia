# Sajia 1.0.18

Notifikasi aplikasi sekarang tampil sebagai toast di bagian atas layar.

- status pembayaran dan aktivasi Cloud tidak lagi tertutup bottom sheet;
- notifikasi kasir, stok, menu, meja, sinkronisasi, pengaturan, dan dashboard
  owner tidak lagi bertumpuk dengan navigasi atau popup aksi;
- notifikasi terbaru menggantikan notifikasi sebelumnya, dapat ditutup melalui
  tombol, atau dengan swipe ke atas.

## Instalasi Android

- APK ditujukan untuk perangkat Android ARM64 dengan Android 8.0 atau lebih baru.
- Build ini adalah distribusi langsung GitHub, bukan build Google Play.
- Versi aplikasi: `1.0.18` (`versionCode 2019`).
- Pengguna versi sebelumnya dapat memperbarui langsung tanpa uninstall.
