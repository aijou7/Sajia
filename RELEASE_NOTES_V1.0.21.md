# Sajia 1.0.21

Perbaikan layout PIN untuk tablet Android.

- Keypad saat membuat atau memasukkan PIN kini memiliki tinggi baris tetap dan
  rapat di tablet layar lebar.
- Semua digit `0–9` serta tombol hapus dapat terlihat tanpa jarak antarbari
  yang berlebihan.
- Perbaikan berlaku untuk pembuatan PIN owner dan halaman login PIN.

## Instalasi Android

- Android 8.0 atau lebih baru.
- Pilih APK **V8A 64-bit** untuk kebanyakan perangkat baru.
- Pilih APK **V7A 32-bit** untuk tablet atau ponsel lama yang 32-bit.
