# Sajia 1.0.15

Pembaruan visual dengan warna yang lebih tegas dan nyaman dibaca:

- warna Sajia sekarang dipakai sebagai aksen pada tombol dan tindakan utama;
- teks utama kembali hitam, teks pendukung abu-abu, dan teks di atas tombol tetap putih;
- frame, field, kartu, divider, dan permukaan memakai putih serta abu-abu netral;
- kartu informasi berkontras tinggi memakai hitam dengan tulisan putih;
- warna hijau, oranye, dan merah tetap dipakai khusus untuk status operasional;
- pedoman brand diperbarui agar pola accent-only tetap konsisten pada fitur berikutnya.

## Instalasi Android

- APK ditujukan untuk perangkat Android ARM64 dengan Android 8.0 atau lebih baru.
- Build ini adalah distribusi langsung GitHub, bukan build Google Play.
- Versi aplikasi: `1.0.15` (`versionCode 2016`).

## Penting untuk pengguna versi lama

Signing key beta GitHub diperbarui pada versi ini. Jika Sajia v1.0.14 atau lebih
lama sudah terpasang, buat backup dari aplikasi terlebih dahulu, uninstall versi
lama, lalu instal APK v1.0.15. Release GitHub berikutnya akan memakai signing key
yang sama sehingga bisa diperbarui normal tanpa uninstall lagi.
