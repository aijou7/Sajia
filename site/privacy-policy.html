Kebijakan Privasi Sajia

Sajia adalah aplikasi kasir dan operasional F&B yang dikembangkan oleh Aijou Teknologi Digital. Kebijakan ini menjelaskan data apa yang diproses saat aplikasi digunakan.

Data yang diproses

Aplikasi dapat menyimpan atau memproses data berikut:

  • Data outlet seperti nama, alamat, nomor telepon, dan pengaturan struk.
  • Data operasional seperti menu, kategori, meja, transaksi, riwayat penjualan, dan laporan.
  • Data staff seperti nama, role, akses cabang, dan PIN yang disimpan dalam bentuk hash.
  • Email owner untuk login, pemulihan perangkat, dan verifikasi lisensi.
  • Data teknis seperti status koneksi, sinkronisasi, dan konfigurasi printer Bluetooth.

Penyimpanan data

Pada mode lokal, data utama disimpan di perangkat pengguna. Jika fitur cloud atau sinkronisasi aktif, sebagian data operasional dapat dikirim ke server backend Sajia/Supabase untuk backup, pemulihan perangkat, dan dashboard lintas cabang.

Izin aplikasi

  • Internet digunakan untuk login, sinkronisasi, lisensi, dan dashboard cloud.
  • Bluetooth digunakan untuk menghubungkan printer struk.
  • Notifikasi digunakan untuk pemberitahuan operasional seperti pesanan atau dapur.

Pembagian data

Kami tidak menjual data pengguna. Data hanya diproses untuk menjalankan fitur aplikasi, autentikasi, backup, sinkronisasi, dukungan teknis, dan kepatuhan hukum.

Keamanan

PIN staff disimpan dalam bentuk hash. Akses cloud menggunakan autentikasi email. Pengguna tetap bertanggung jawab menjaga keamanan perangkat, email, dan akses owner.

Penghapusan data

Pengguna dapat menghapus data lokal dengan menghapus data aplikasi dari perangkat. Untuk permintaan penghapusan data cloud, hubungi pengembang.
