# Sajia 1.0.23

## Promo berdasarkan periode tanggal

- Dashboard Owner sekarang dapat membuat promo untuk rentang tanggal tertentu,
  misalnya 20–29 September, dengan promo aktif setiap hari sampai tanggal akhir.
- Jadwal mingguan tetap tersedia sebagai pilihan terpisah agar pengaturannya tidak
  membingungkan.
- Periode tanggal berlaku inklusif dan tetap mengikuti jam mulai–selesai promo.
- Cache lokal dan sinkronisasi promo sudah kompatibel dengan jadwal periode baru.

## Instalasi Android

- Android 8.0 atau lebih baru.
- Pilih APK **V8A 64-bit** untuk kebanyakan perangkat baru.
- Pilih APK **V7A 32-bit** untuk tablet atau ponsel lama yang 32-bit.
